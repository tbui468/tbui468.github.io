Golf Score System

IGCSE Computer Science 0478 - Pre-release Material (March 2022)

Create a program to record and score a round of golf.

A score in golf is the number of strokes needed to get the ball into a hole. The player with the lowest total number of strokes wins the round.

A golf course contains either 9 or 18 holes. There may be 2 to 4 players.

Task 1 - Setting Up the Round

  • Input the number of players.
  • Input each player's name.
  • Input the number of holes (9 or 18).
  • Input the course par.
  • Display all entered information for checking.

Task 2 - Scoring the Round

  • For each hole, ask every player for their score.
  • Each score must be entered twice for verification.
  • If the two entries do not match, re-enter the score.
  • Allow the player to optionally view their running total.

Task 3 - Determine the Winner

  • Calculate each player's total score.
  • Display the score relative to par.
  • Identify and display the winning player.
  • Display the winning score.

Additional Features

  • Display every player's score for every hole.
  • Display all hole-in-ones.
  • Display the average score for the round.
  • Display the average score for each hole.

Validation Rules

  • Number of players must be between 2 and 4.
  • Number of holes must be 9 or 18.
  • Scores must be verified by entering them twice.
  • All prompts and error messages must be clear.
Consider using a 2D array: Score[Player, Hole] to store each player's score for every hole.
