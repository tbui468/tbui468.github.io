Task 1 - Becoming a Member

Create a system to record new members of Friends of Seaview Pier.

Validation requirements
  • Presence check on first name
  • Presence check on last name
  • Format check join date to match format DD/MM/YYYY
  • Input the member's first name.
  • Input the member's last name.
  • Input whether the member wishes to volunteer.
  • If volunteering, select one area:
    • Pier entrance gate
    • Gift shop
    • Painting and decorating
  • Input the date of joining.
  • Input whether the $75 membership fee has been paid.
  • Store all information using suitable data structures.

Task 2 - Using Membership Data

Extend the program so members can be listed according to different categories.

  • Display all members who volunteer.
  • Display volunteers at the pier entrance gate.
  • Display volunteers in the gift shop.
  • Display volunteers helping with painting and decorating.
  • Display members whose membership has expired.
  • Display members who have not paid their $75 fee.

Task 3 - Sponsoring a Wooden Plank

Add an option to allow sponsors to purchase a commemorative brass plaque for a wooden plank.

  • Input the sponsor's name.
  • Input the short plaque message.
  • Store sponsor names separately from plaque messages.
  • Display all entered information for confirmation.
  • Allow incorrect data to be re-entered.
  • Store the completed sponsorship details.
  • Charge the sponsor $200.
